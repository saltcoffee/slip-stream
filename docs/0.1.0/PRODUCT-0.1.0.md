## 1. 产品概述 (Product Overview)

- **Slogan**：Turn folders and tags into a continuous, draggable reference stream for effortless long-form writing.
- **一句话定位**：把文件夹、标签或双链合集变成一条**连续滚动、可直接拖拽引用**的参考资料卡片流。
- **核心定位**：专为长文写作者、研究人员和重度收集控打造的「书桌参考流」视图。将多个数据源（文件夹 / 标签 / 双链合集）渲染为垂直连滚的「实体卡片栈」，彻底解决多篇参考资料在分屏（Split Pane）和标签页之间频繁切换造成的思路打断问题，并让「摘录 → 引用 → 溯源」在一条拖拽手势里闭环。
- **产品形态**：Obsidian 社区插件（Community Plugin），一个独立的 `ItemView`，可停靠右侧栏或作为主区分屏。

### 1.1 设计原则

1. **阅读不打断**：浏览参考资料时不产生新的标签页、不抢占主文档焦点。
2. **引用即溯源**：每一次拖拽落盘都自带可点击、可验证的来源双链。
3. **操作可逆**：折叠、隐藏、移除只影响当前视图，绝不静默修改用户文件（唯一会写文件的是「自动生成 Block ID」，且可关闭）。
4. **数据本地化**：不联网、不上传、不采集，全部在本地 Vault 内完成。

## 2. 问题与目标用户 (Problem & Users)

### 2.1 背景与痛点

| 痛点 | 现状 | 后果 |
| --- | --- | --- |
| 分屏空间不足 | Obsidian 原生 Split Pane 超过 3 个就挤成窄条 | 无法并排对照多篇资料 |
| 标签页切换打断思路 | 在 7–8 篇剪藏笔记间来回切 | 上下文反复重建，写作节奏被打断 |
| 摘录成本高 | 复制正文后要手动补 `[[文件]]` 链接、手动定位段落 | 引用不精确、容易漏标来源 |
| 溯源不精确 | 只能链到文件或标题，难以定位到具体段落 | 回看时找不到原句 |
| 只想要重点 | 剪藏笔记很长，真正有用的只是自己划过的高亮 | 重读成本高 |

### 2.2 目标用户画像 (Personas)

- **深度长文作者**（主）：写年终总结、深度博客、书稿，单篇需要参考 8–20 篇素材。
- **课题研究者 / 学生**：围绕一个课题收集大量论文笔记、剪藏，需要边读边摘边写。
- **运营 / 周报作者**：从多个项目剪藏里汇总信息、拼装周报，追求"扫一眼就能用"。
- **重度收集控（PKM 爱好者）**：拥有大量 Inbox、剪藏、标签体系，痛点是"存了但不看"。

### 2.3 使用场景 (Jobs To Be Done)

1. 打开 `Inbox/项目A剪藏` 文件夹 → 一键铺成卡片流 → 通读 → 拖三段话进主文档，自动带 `[[笔记#^block]]`。
2. 正在写主文档 → 在右侧打开 SlipStream，数据源选「入链 / 出链」→ 相关碎片自动铺在眼前。
3. 打 `#项目A` 标签 → 所有相关笔记成为一条信息流，只看带高亮和 Callout 的部分。
4. 写周报时按标签 / 文件夹聚合本周素材 → 把命中结果当卡片流扫读并摘录。（原生「搜索源」0.1.1 支持，见 §7.1）

## 3. 产品目标与非目标 (Goals & Non-Goals)

### 3.1 本期目标（0.1.0）

- 支持 **文件夹 / 标签 / 入链 / 出链** 四类核心数据源（书签与搜索计划 **0.1.1**，见 §7.1）。
- 提供 **完整 / 摘要 / 紧凑** 三种卡片密度与连续滚动阅读体验。
- 提供 **段落级拖拽引用**，落盘时自动生成带来源双链的引用块，并可选自动写入 Block ID。
- 提供 **引用历史与跳回原文**：每次引用留痕，可一键回到来源段落。
- 提供基础设置面板、命令与右键菜单入口，全流程可键盘/鼠标完成。

### 3.2 非目标（0.1.0 明确不做）

- 不做笔记编辑器替代品，不做 AI 摘要 / 自动改写。
- 不做移动端（触屏拖拽另行设计，见 §12）。
- 不做多 Vault、跨 Vault 聚合。
- 不做云同步、协作、遥测上报。
- 不做卡片内的内容编辑（卡片只读；需要修改时在新标签页打开原文）。
- 不做发布（Publish）与导出。
- 0.1.0 **不做**「书签组 / 原生搜索」数据源（依赖非公开 API，**0.1.1** 实现）。

## 4. 核心价值与差异化 (Value Proposition)

| 对比对象 | 差异 |
| --- | --- |
| 原生 Split Pane | 一个视图内纵向连滚 10–20 篇，不占多个分屏 |
| 原生搜索 / 文件列表 | 直接渲染**正文卡片**，而非文件名；可阅读、可折叠、可拖拽 |
| Scrivener Scrivenings | 移植到 Obsidian，并叠加「拖拽引用 + 双链溯源」 |
| Ulysses | 保留本地 Markdown 与双链生态，不做专有库 |

**Aha Moment**：用户在卡片流中看到一句关键数据，拖进右侧主文档，松手即得 `> 引用内容 —— [[来源#^block-id]]`，点击可精准跳回原段落。

## 5. 术语表 (Glossary)

| 术语 | 含义 |
| --- | --- |
| 卡片流 / Card Stream | 将多个笔记渲染成的垂直连续卡片序列 |
| 卡片栈 / Card Stack | 卡片流中可折叠、可固定的单卡片集合比喻 |
| 数据源 / Source | 决定卡片集合的聚合维度（文件夹、标签、入链 / 出链） |
| 密度 / Density | 卡片正文的展开程度：完整 / 摘要 / 紧凑 |
| 拖拽引文 / Drag-to-Cite | 从卡片拖拽文本到主文档并自动生成引用 |
| Block ID | Obsidian 的块引用标识，形如 `^cd8f2a`，写在段落末尾 |
| 落盘模板 / Drop Template | 引用插入时使用的文本模板 |
| 主文档 / Main Doc | 当前正在编辑、接收拖拽内容的目标笔记 |
| 引用历史 / Citation History | 每次引用（来源、块、目标、模板、时间）的本地记录，可跳回原文 |

## 6. 用户旅程 (User Journey)

### 6.1 主流程

1. **唤起视图**：用户在文件树右键 `Inbox/剪藏参考` 文件夹（或标签面板右键 `#项目A`），选择 **「Open in SlipStream（在卡片流中打开）」**；也可通过命令面板、Ribbon 图标、或已打开的 SlipStream 视图顶部的数据源切换器唤起。
2. **分屏对照**：插件在**主编辑区旁**或**右侧栏**开启独立 `ItemView`，将该数据源下的笔记渲染为垂直排列的「卡片栈」（默认按修改时间倒序）。视图记住上次停靠位置。
3. **连续扫读**：用户直接滚动滚轮，像刷信息流一样连续浏览正文 / 高亮 / 列表。不相关的卡片可 **折叠（Collapse）** 或 **暂时隐藏（Dismiss）**，隐藏项在「显示已隐藏」开关下可恢复。
4. **拖拽引用（Aha Moment）**：用户在卡片中看到关键数据或金句，鼠标悬停段落时左侧浮现**拖拽手柄**，按住拖入右侧正在编写的主文档编辑器。
5. **溯源闭环**：松手瞬间，文字精准插入目标光标处，并按用户预设模板转化为带双链溯源的文本块，例如：
   `> 引用内容 —— [[来源笔记#^cd8f2a|来源笔记]]`
6. **反馈**：插入成功后编辑器光标停在插入内容末尾，右下角短暂提示「已插入引用」。

### 6.2 异常 / 边界流

| 场景 | 预期行为 |
| --- | --- |
| 没有打开任何主文档 | 拖拽落盘时提示「请先打开一篇笔记作为主文档」，或降级为复制到剪贴板并提示 |
| 目标编辑器处于阅读模式 | 提示切换到编辑/实时预览模式，或复制到剪贴板 |
| 数据源为空 | 卡片区显示空状态插画 + 「未找到笔记」+ 快捷切换数据源按钮 |
| 数据源解析失败 | 卡片区显示错误态 + 「重试」按钮 + 简要错误信息 |
| 单篇笔记极大（>1MB） | 默认摘要模式渲染，并提示「大文件已折叠，展开可能较慢」 |
| 卡片正文含嵌入 / Dataview 等动态块 | 尽量降级为纯文本或占位提示，不阻塞其他卡片 |
| Block ID 写入与同步冲突 | 写入前二次校验文件内容；失败时降级为「仅文件级双链」并提示 |
| 拖拽跨弹出窗口（Popout） | 0.1.0 仅支持同一窗口内拖拽，跨窗口提示改用复制 |

## 7. 功能规格说明 (Functional Specifications)

### 7.1 数据源接入层 (Data Sources)

视图顶部提供轻量的**数据源切换器（Source Bar）**，支持以下聚合维度，并可配置包含/排除规则：

| 数据源 | 触发入口 | 集合规则 | 落地版本 |
| --- | --- | --- | --- |
| **Folder（文件夹）** | 文件夹右键菜单 | 该文件夹下所有 `.md`；可选「含子文件夹」；可配置排除 glob（如 `_drafts/**`）；若同时存在 `zh/` 与 `en/` 子目录，按界面语言自动选择 | 0.1.0 ✅ 公开 API |
| **Tag（标签）** | 标签面板右键 / Source Bar 输入 | 命中指定 `#tag` 的所有笔记，含子标签 `#tag/child`；匹配 frontmatter `tags` 与行内标签 | 0.1.0 ✅ `MetadataCache` |
| **Backlinks（入链）** | 主文档内触发 | 指向当前主文档的所有笔记（提及当前笔记的碎片） | 0.1.0 ✅ `resolvedLinks` |
| **Outlinks（出链）** | 主文档内触发 | 当前主文档链接到的所有笔记 | 0.1.0 ✅ `MetadataCache` |
| **Bookmark Group（书签组）** | Bookmark 面板右键 / Source Bar | 复用 Obsidian 书签分组下的文件集合 | 0.1.1 🟡 内部接口，需特性检测 + 降级 |
| **Search Query（搜索）** | Source Bar 输入 | 复用 Obsidian 原生搜索语法的结果集 | 0.1.1 🟡 原生搜索 API 非公开 |

**数据源交互细节**

- Source Bar 展示：`[图标] 数据源类型 · 当前值 ▾`，点击展开切换菜单。
- 支持把一个文件夹/标签**钉**为视图的固定数据源，供 `getViewState` 持久化。
- 「入链 / 出链」源需要**唤起视图时**存在活动主文档（作为锚点），否则置灰并提示。
- 数据源变更后**增量刷新**：仅重算集合，不清空已渲染卡片缓存。
- 集合上限保护：默认最多 200 篇，超出提示并可「加载更多」，避免一次性渲染爆炸。

### 7.2 卡片栈视图交互 (Card Stack UI)

#### 7.2.1 三种显示密度（视图顶部一键切换，持久化）

| 密度 | 内容 | 适用 |
| --- | --- | --- |
| **完整模式 Full Stream** | 渲染完整 Markdown 正文（类 Scrivener Scrivenings 连续文档），含标题、正文、列表、代码块、Callout | 深度阅读与摘录 |
| **摘要模式 Snippet / Digest** | 标题 + YAML 核心标签 + 前 N 字（默认 150）+ **文中所有 `==高亮==`** + **Callout 块（默认包含，限长可折叠，见 §7.4）** | 剪藏控刚需，只看划过重点的部分 |
| **紧凑模式 Compact** | 仅卡片标题栏，点击单卡展开正文（手风琴） | 快速定位、批量管理 |

#### 7.2.2 单卡片结构（Card Header + Body）

- **Header 左侧**：折叠/展开箭头、笔记标题（点击在**新标签页**打开原文件）、字数小标。
- **Header 右侧**：
  - **固定到顶部 Pin**：置顶该卡片（可多选，置顶组稳定排序）。
  - **复制引用（Copy Citation）**：把当前卡片/选中段落按默认模板复制到剪贴板，作为拖拽的键盘与无障碍等价路径。
  - **从当前流移除 Dismiss**：仅从本视图隐藏，不删除文件；可在「显示已隐藏」恢复。
- **Body 左侧**：每个块级元素旁浮现拖拽手柄（见 §7.3）。
- **卡片足部**：来源路径面包屑、修改时间、标签 chips。

#### 7.2.3 实时过滤与排序

- **过滤框**：按关键词实时筛选卡片（匹配标题、正文、标签），命中词在卡片内高亮；输入防抖 120ms。
- **排序下拉**：按修改时间、创建时间、文件名、**自定义拖拽顺序**；支持升/降序。
- **自定义拖拽排序**：在紧凑模式可拖拽卡片头部调整顺序，顺序按数据源持久化到视图状态。
- **批量操作**：全选 / 折叠全部 / 展开全部 / 清除隐藏。

#### 7.2.4 视图壳（View Shell）

- 顶部 Source Bar + 密度切换 + 过滤框 + 排序 + 更多菜单（刷新、显示已隐藏、清除缓存）。
- 中部卡片流虚拟滚动区。
- 底部状态条：`共 N 篇 · 已隐藏 M · 引用 K 次`（点击「引用 K 次」打开引用历史）。

### 7.3 跨视图拖拽引文引擎 (Drag-to-Cite Engine)

#### 7.3.1 段落级嗅探

- 鼠标在卡片正文移动时，自动识别当前悬停的 HTML **块级元素**（`<p>`、`<li>`、`<blockquote>`、`<pre>`、Callout），并在其左侧边缘浮现微弱**拖拽手柄（Drag Handle）**。
- 手柄 hover 高亮当前将作为 Payload 的块；Tooltip 显示「拖拽引用此段」。

#### 7.3.2 自由划词拖拽

- 若用户先用鼠标选中了一段**跨块文本**，拖拽时以选中文本作为 Payload（优先于块嗅探）。
- 选中态下显示浮动「引用」按钮作为点击替代（兼顾手感和可访问性）。

#### 7.3.3 自动生成 Block ID（可选，默认开启）

- 开启「精确到块引用（`#^id`）」后，拖拽触发瞬间后台静默读取来源文件，定位到对应段落**行尾**，写入随机短哈希（默认 6 位 base36，如 `^cd8f2a`）。
- 约束：仅对段落 / 列表项 / 引用块 / Callout 写入；**不写入代码块、表格、Frontmatter**。
- 去重：同一文件内保证唯一；已存在 Block ID 时直接复用。
- 关闭该选项时，落盘退化为文件级双链。

#### 7.3.4 可配置落盘格式（Drop Templates）

| 模板 | 形式 | 落盘示例 |
| --- | --- | --- |
| **A 标准引用** | Blockquote + 出处 | `> {{content}}`<br>`> — [[{{filename}}#^{{blockId}}\|{{title}}]]` |
| **B 行内融合** | 正文内联 + 括注 | `{{content}} ([[{{filename}}]])` |
| **C 嵌入式** | 直接嵌入原块 | `![[{{filename}}#^{{blockId}}]]` |
| **D 自定义** | 用户编辑模板字符串 | 支持下列变量 |

**模板变量**：`{{content}}`、`{{filename}}`（不含扩展名）、`{{path}}`、`{{title}}`、`{{blockId}}`、`{{heading}}`、`{{url}}`（`obsidian://` 本地链接）、`{{date}}`。

**空 Block ID 降级**：模板 A/C 在未获取到 `blockId` 时自动降级为文件级（A→`[[file]]`，C→`![[file]]`），避免生成 `#^` 坏链；模板 B/D 同理去掉空的块引用片段。

**落盘后处理**：

- 插入位置：主文档**当前光标处**；若有选区，默认替换选区（可在设置中改为「保留选区并追加」）。
- 插入后光标移到内容末尾；插入内容使用 `editor.replaceSelection`，保持撤销栈连续（一次 Ctrl+Z 可撤销整次插入）。
- 引用去重：同一会话内重复拖拽同一块，默认去重并提示；可在设置关闭。

### 7.4 设置面板 (Settings)

| 分组 | 设置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 常规 | 默认显示密度 | 枚举 full/snippet/compact | snippet | 新开视图的初始密度 |
| 常规 | 界面语言 | 枚举 auto/zh/en | auto | 跟随 Obsidian，或强制中文 / English |
| 常规 | 视图默认停靠位置 | 枚举 right-sidebar/split | right-sidebar | 唤起时打开位置 |
| 数据源 | 文件夹包含子文件夹 | 布尔 | true | Folder 源默认行为 |
| 数据源 | 排除 glob | 文本 | 空 | 逗号分隔，如 `_drafts/**,*.tmp.md` |
| 数据源 | 集合上限 | 数字 | 200 | 超出需手动加载更多 |
| 卡片 | 摘要字数 | 数字 | 150 | 摘要模式截断长度 |
| 卡片 | 摘要包含高亮 | 布尔 | true | 摘要模式是否包含 `==高亮==` 文本 |
| 卡片 | 摘要包含 Callout | 布尔 | true | 摘要模式是否包含 Callout 块 |
| 卡片 | 摘要 Callout 上限 | 数字 | 280 | 摘要模式单个 Callout 最多展示的字符数，超出折叠 |
| 卡片 | 紧凑模式默认折叠 | 布尔 | true | 紧凑模式行为 |
| 引用 | 精确到块引用 | 布尔 | true | 是否自动写 Block ID；首次拖拽时弹一次说明，状态栏显示当前开关 |
| 引用 | 默认落盘模板 | 枚举 A/B/C/D | A | 新建视图继承 |

### 7.6 引用历史与跳回原文 (Citation History & Jump-back)

**目标**：每次引用都留下可追溯记录；即使离开当前文档，也能一键跳回来源段落。

- **记录内容**：时间、来源文件路径、`#^blockId` / 标题、目标文档路径、使用模板、内容摘要（前 120 字）。
- **产生时机**：拖拽落盘成功、或「复制引用」成功时追加一条。
- **入口**：视图底部状态条 `引用 K 次` 点击；命令面板 `Open citation history`；更多菜单。
- **面板操作**：按时间倒序列表 + 关键词筛选；每条支持「跳回原文」「打开目标文档」「再复制一次」；支持清空历史。
- **跳回原文**：`workspace.openLinkText(path + '#^blockId', '', false)` 打开来源并定位到块；无 blockId 时按标题 / 文件定位。
- **存储与上限**：本地 `data.json` 保存，默认上限 200 条（可在设置调整 / 关闭）；超出滚动淘汰最旧。
- **空 / 错误态**：无历史显示「还没有引用记录」；读取失败显示错误 + 重试。
- **隐私**：仅本地存储、不上传；可在设置一键清空。

## 8. 交互状态与边界 (States & Edge Cases)

每个视图/卡片必须覆盖完整状态：

- **加载态**：卡片骨架屏（skeleton），顶部显示「正在解析 N 篇…」。
- **空态**：无数据源、数据源为空、过滤无结果、全部隐藏、引用历史为空 —— 各自给出针对性文案与恢复操作。
- **错误态**：数据源解析失败、文件读取失败、Block ID 写入失败 —— 展示错误原因 + 重试 + 降级路径。
- **部分失败**：单卡渲染失败不影响其他卡片，显示「该卡片渲染失败 · 重试」。
- **大集合**：> 200 篇分页；虚拟滚动；单篇 > 1MB 提示。
- **并发写入**：Block ID 写入前做 diff 校验，不匹配则放弃写入并提示；与 Obsidian Sync 冲突时以文件最新版本为准。
- **撤销**：任何对文件的写入（Block ID 注入）都应可撤销或给出明确提示。
- **焦点与键盘**：Tab 可在卡片间移动，Enter 展开，Space 折叠，Alt+↑/↓ 调整顺序；Esc 关闭菜单。

## 9. 非功能性需求 (Non-Functional Requirements)

### 9.1 性能

- 打开 20 篇卡片流，首屏骨架 < 300ms；首个卡片正文可见 < 800ms（中等性能设备）。
- 滚动 60fps 目标；离屏卡片不做 Markdown 渲染（虚拟滚动，`rootMargin` 约 400px 预渲染）。
- 过滤输入防抖 120ms；Markdown 渲染并发 ≤ 3。
- 缓存：按「文件 mtime + 解析设置签名」缓存渲染结果，避免重复解析。

### 9.2 兼容性

- Obsidian 桌面端 ≥ `1.8.7`（见开发文档 `manifest.minAppVersion`）。
- 支持浅色 / 深色主题，遵循 Obsidian CSS 变量，不硬编码颜色。
- macOS / Windows / Linux 同构；不依赖 Node 原生模块。
- 与常见社区插件（Dataview、Templater、Style Settings）共存，不修改全局样式。

### 9.3 可访问性 (Accessibility)

- 全部操作可键盘完成；拖拽提供「点击引用」等价路径。
- 交互元素带 `aria-label` / `role`；焦点可见环。
- 尊重「减少动态效果」（`prefers-reduced-motion`）。
- 对比度满足 WCAG AA。

### 9.4 隐私与安全

- 插件自身**不主动联网**（无网络请求、无遥测、无崩溃上报）；渲染笔记里的远程图片/iframe 由系统或第三方插件加载，不属插件发起的请求。
- 不在日志中输出笔记正文；调试日志默认关闭且仅含路径与错误码。
- 文件写入仅限：Block ID 注入（用户拖拽时触发）；全部在用户显式操作下发生。
- 引用历史仅本地保存（默认上限 200 条），不上传，可在设置一键清空。

### 9.5 国际化 (i18n)

- 0.1.0 至少支持简体中文与英文，跟随 Obsidian 语言设置。
- 所有 UI 文案集中在 i18n 资源，禁止硬编码。

由于本插件本地运行、默认无遥测，0.1.0 以**可用性验收 + 内测反馈**为主，指标用于产品判断而非在线统计：

| 指标 | 定义 | 目标 |
| --- | --- | --- |

## 12. 风险与开放问题 (Risks & Open Questions)

| # | 风险 / 问题 | 影响 | 应对 |
| --- | --- | --- | --- |
| R1 | 原生搜索 / 书签 API 非公开 | 0.1.0 无法稳定实现这两类数据源 | 0.1.0 不实现，列入 **0.1.1**；落地需特性检测 + 可降级 |
| R2 | 自动写 Block ID 会改动用户文件 | 有副作用、可能触发同步冲突 | 默认开启但可关闭；写入前校验；失败降级为文件级双链 |
| R3 | 跨弹出窗口 HTML5 拖拽不可靠 | 多窗口场景体验断裂 | 0.1.0 限制同窗口；后续用 pointer 事件 + elementFromPoint 方案 |
| R4 | 逐块渲染影响 Markdown 完整性（脚注/嵌入） | 渲染保真度下降 | 逐块渲染 + 跨块特性降级提示；提供全量渲染开关 |
| R5 | 超大笔记 / 超多卡片导致卡顿 | 性能劣化 | 虚拟滚动 + 分页 + 摘要优先 + 并发上限 |
| R6 | 移动端无原生拖拽 | 移动端不可用 | `isDesktopOnly: true`，后续专门设计 |

**已确认决策（0.1.0）**：

| # | 决策 | 结论 | 产品/用户理由 |
| --- | --- | --- | --- |
| 1 | 是否纳入「书签组 / 搜索」数据源 | **0.1.0 不做，推迟到 0.1.1** | Folder / Tag / 入链 / 出链 已覆盖核心 JTBD；书签与搜索依赖非公开内部 API、上架审核风险高，首版先把可靠性做扎实，0.1.1 再上 |
| 2 | 摘要模式是否默认包含 Callout | **需要（默认包含）** | 剪藏笔记里 Callout 往往承载结论/摘录精华，正是"只看重点"的核心；但用字数上限（默认 280）+ 折叠兜住过长问题，避免摘要变成长文 |
| 3 | 默认落盘模板 | **需要 A（引用块 + 出处）** | 与产品 Aha Moment「> 引用内容 —— 来源」一致，引用关系肉眼可辨、符合写作与学术习惯；B/C 作为可选满足不同书写风格 |
| 4 | Block ID 自动生成是否默认开启 | **需要（默认开启）** | 段落级精准溯源是核心差异化，关闭即退化为文件级、丢失"跳回具体段落"价值；以「拖拽时才写、首次说明、状态栏可见、一键关闭」控制写文件的副作用与信任成本 |
