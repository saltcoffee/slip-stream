# SlipStream

**把文件夹、标签或双链合集变成一条连续滚动、可直接拖拽引用的参考资料卡片流**，让长文写作不再被分屏和标签页打断。

中文 · [English](README.md)

---

## 它能做什么

- **书桌式卡片流**：右键一个文件夹（或标签、入链/出链），在侧栏打开 SlipStream，把十几篇笔记直接铺成一排可连续滚动的卡片。
- **三种阅读密度**：完整正文 / 只看重点（摘要：高亮 + Callout）/ 紧凑标题栏，随读随切。
- **点击、键盘与拖拽引用**：明确绑定稿件和位置，选中文字或打开段落操作后引用；拖拽写入实际接收编辑器的落点。
- **可信溯源**：摘要和划词引用实际展示／选中的内容，完整段落保留 Markdown。显示完整块、块内片段、跨块起点、标题或文件精度，来源链接包含完整路径以区分同名笔记。
- **引用记录**：区分插入与复制，保存真实目标；可跳回来源、查看目标或再次复制。成功入稿另存独立的最小引用快照。

## 安装

1. 打开 Obsidian「设置 → 第三方插件」。
2. 点击「浏览」，搜索 **SlipStream**。
3. 点击「安装」，然后「启用」。

> 目前仅支持桌面端。

## 快速上手

1. 在文件树**右键一个文件夹**，选择「Open in SlipStream」；或用命令面板 `SlipStream: Open`。
2. 在顶部切换数据源（文件夹 / 标签 / 入链 / 出链）。
3. 用顶栏切换阅读密度、过滤和排序。
4. 在稿件中定位光标／选区，运行命令 `SlipStream: 将当前笔记设为引用目标`，或在顶栏点击「选择目标」。切换阅读资料不会改变绑定，关闭视图或重启后须重新选择。
5. 选择卡片正文中的文字，或打开段落的「⋯」操作，点击「引用到目标」。Tab 可进入段落操作，上下方向键切换片段，Enter／Space 打开操作，Esc 取消。卡片头复制只使用有效选区，不会默认复制第一段。
6. 也可把段落左侧的**抓手**拖到实际稿件落点。目标选区支持替换／追加；多光标、过期位置或无法识别的落点会停止并提示重新定位。

首次需要新增来源块 ID 时会说明并请求选择。仅浏览、划词或取消不会新增 ID；撤销稿件引用会保留来源 ID。复制同样遵循这条规则。关闭自动生成仍可复用可靠的已有 ID。

去重只提醒本次会话曾向同一篇稿件成功插入的同一片段；复制不占用入稿名额，其他稿件仍可引用。撤销或删除不会立即消除提醒，可以明确选择「仍然插入」。正文成功但记录失败时，使用「仅重试保存记录」，不要重复插入。

## 设置

- 界面语言（跟随 Obsidian / 中文 / English）
- 默认阅读密度、视图停靠位置
- 文件夹是否包含子文件夹、排除规则
- 摘要字数、是否包含高亮 / Callout
- 是否自动生成块引用、默认引用格式
- 按目标文章的会话去重、目标选区替换／追加
- 记录引用总开关、历史上限、独立快照用量与清理
- 外观（卡片宽度、字号）与高级选项

## 引用模板与记录

A 为逐行引用，B 保留正文并附来源，C 只嵌入完整且有可靠块锚点的单块。选区、摘要或无锚点来源使用 C 时需明确选择其他方式。

D 保留已有模板与 `content`、`filename`、`path`、`title`、`blockId`、`heading`、`url`、`date` 变量，日期为本地日期。新增安全来源 `link` 与逐行引用正文 `blockquoteContent`，推荐写法：

```text
{{blockquoteContent}}
> — {{link}}
```

0.1.3 新增可靠性校验：未知变量、空输出、缺少可验证的来源链接或同名歧义会阻止本次引用；不会清空模板，可修正模板或本次用 A。

历史默认保留 200 条，快照独立保存，上限为 1,000 条或 10 MiB，以先到者为准。达到快照上限仍可引用，但会明确提示本次未保存核查依据，不会静默淘汰旧快照。清空历史保留快照，清空快照保留笔记与历史；关闭「记录引用」停止新增两类记录，并保留既有数据。历史不代表稿件目前仍保留这些引用。

升级旧数据时先在插件实际目录生成唯一命名的 `data-backup-*.json`，再迁移；旧记录的未知动作／目标不会补造。备份失败、数据不可读或版本较新时保留原文件，禁用记录写入和新块 ID，仍可使用不新增 ID 的引用。

## 隐私

- 完全本地运行，插件不会主动联网、不上传任何内容、不收集数据。
- 引用历史、最小入稿快照和升级备份仅保存在你自己的 Vault 中；不保存整篇稿件或整篇资料（引用本身覆盖的块除外）。可分别清理历史与快照。
