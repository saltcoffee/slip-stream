# SlipStream

**把文件夹、标签或双链合集变成一条连续滚动、可直接拖拽引用的参考资料卡片流**，让长文写作不再被分屏和标签页打断。

中文 · [English](README.md)

---

## 它能做什么

- **书桌式卡片流**：右键一个文件夹（或标签、入链/出链），在侧栏打开 SlipStream，把十几篇笔记直接铺成一排可连续滚动的卡片。
- **三种阅读密度**：完整正文 / 只看重点（摘要：高亮 + Callout）/ 紧凑标题栏，随读随切。
- **拖拽即引用**：把卡片里的一段话拖进正在写的文档，自动插入带来源双链的引用块（如 `> 引用内容 —— [[来源#^块]]`）。
- **精准溯源**：自动为被引用的段落写入块引用，点击即可跳回原句。
- **引用历史**：每次引用都有记录，可一键「跳回原文」，再也不用翻找。

## 安装

1. 打开 Obsidian「设置 → 第三方插件」。
2. 点击「浏览」，搜索 **SlipStream**。
3. 点击「安装」，然后「启用」。

> 目前仅支持桌面端。

## 快速上手

1. 在文件树**右键一个文件夹**，选择「Open in SlipStream」；或用命令面板 `SlipStream: Open`。
2. 在顶部切换数据源（文件夹 / 标签 / 入链 / 出链）。
3. 用顶栏切换阅读密度、过滤和排序。
4. 把鼠标移到卡片段落左侧的**抓手**上，拖进右侧正在写的文档，松手即完成引用。

## 设置

- 界面语言（跟随 Obsidian / 中文 / English）
- 默认阅读密度、视图停靠位置
- 文件夹是否包含子文件夹、排除规则
- 摘要字数、是否包含高亮 / Callout
- 是否自动生成块引用、默认引用格式
- 引用去重、引用历史开关与上限
- 外观（卡片宽度、字号）与高级选项

## 隐私

- 完全本地运行，插件不会主动联网、不上传任何内容、不收集数据。
- 引用历史仅保存在你自己的 Vault 中，可随时清空。
